Question 2: Which other xv6 system call(s) could be made faster using this shared page? Explain how. 

1. getpid(): It returns current process ID and it can be shared as it is already
implemented and this helps avoid kernel trap.

2. uptime(): It returns system tick count, and it can be shared as it is frequently 
read but never written by user. This also helps avoid kernel trap for each read.

3. time(): It returns system time, and it can be shared as it it updates once per
tick. This allows fast user access to current time.
